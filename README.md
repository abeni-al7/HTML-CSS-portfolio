# HTML & CSS Portfolio

A collection of static pages built with only HTML and CSS while learning responsive web design. The five main projects follow the freeCodeCamp Responsive Web Design certification project specs (the landing page form posts to freeCodeCamp's test endpoint).

## Projects

| Folder | Page |
| --- | --- |
| `tribute_page/` | Tribute page for Albert Einstein |
| `survey_form/` | "Wow Burger" survey form |
| `product_landing_page/` | iPhone product landing page with features, an embedded video, pricing and an email sign-up form |
| `technical_documentation/` | Simple Python documentation page with a side navbar (introduction, syntax, control structures, modules, file and error handling, libraries) |
| `personal_portfolio/` | Personal portfolio page with welcome, projects and contact sections |
| `youtube_tuts/profile_page/` | Profile card UI built while following a YouTube tutorial |

## Built with

HTML and CSS only. Each folder has its own `index.html` and stylesheet.

## Run it

Open any folder's `index.html` in a browser, or serve the repo with VS Code Live Server (`.vscode/settings.json` sets it to port 5501).
